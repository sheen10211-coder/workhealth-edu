# 職人健促領航島｜全課程學習手冊與大綱

## 一、課程簡介與核心宗旨
本課程「職人健促領航島」專為大專學生設計，旨在銜接校園與未來職場，培養青年勞動者必備的「職業安全衛生認知」與「健康促進實務技能」。透過 3D 島嶼互動式學習，打破傳統生硬的法規講義，引導學習者具備危害辨識、心理調適、動態工作以及主動設計企業健康促進方案的核心素養。

## 二、六座核心島嶼架構與學習地圖
| 島嶼編號與名稱 | 單元核心目標 | 建議研讀時數 |
| :--- | :--- | :--- |
| **01 職場衛生啟航島** | 掌握職業安全衛生法規核心精神、三大勞工權利與危害分類 | 2 小時 |
| **02 危害辨識探索島** | 學習物理、化學、人因工程之危害辨識與控制階層策略 | 3 小時 |
| **03 身心減壓調適島** | 自我檢測職業過勞風險、應對職場壓力與不法侵害預防 | 2.5 小時 |
| **04 職場體能活力島** | 掌握電腦人體工學坐姿、打破久坐作息與辦公室伸展技巧 | 2 小時 |
| **05 健促方案設計島** | 運用 PDCA 循環，獨立規劃兼具創意與實效的職場健促企劃 | 4 小時 |
| **06 職業健康實踐島** | 分析健康職場標竿案例、理解 ESG 與勞工健康永續推動機制 | 2.5 小時 |

## 三、學習成果評量方式
1. **各島單元自我檢核（30%）**：完成各島教材末端之觀念檢核題。
2. **職場健促企劃書撰寫（40%）**：於第 05 島實作單元，繳交一份完整的企業或校園健康促進活動企劃案。
3. **綜合實踐反思日誌（30%）**：研讀第 06 島案例後，撰寫個人未來職涯健康維護承諾書。
